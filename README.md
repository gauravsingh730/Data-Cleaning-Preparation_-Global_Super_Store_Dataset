# Sales Data Cleaning Using Microsoft Excel

## Project Description

This project was completed as part of my **Data Analyst Internship at SWYNEX Technologies**.

The objective was to identify and resolve common data quality issues and prepare the sales dataset for further analysis using **Microsoft Excel**.

## Tools Used
- Microsoft Excel

## Dataset Information

The dataset contains sales transaction records with details such as:
- Order ID and Order Date
- Customer Name and Customer Segment
- Country and Region
- Product Category and Product Name
- Quantity and Unit Price
- Discount, Total Sales and Profit

## Data Cleaning Tasks

- Identifying missing values
- Checking duplicate records
- Correcting data formats
- Standardizing inconsistent values
- Checking incorrect and unusual entries
- Preparing the dataset for analysis

## Project Files

- `Global Superstore_Raw_Data.csv` – Original dataset
- `Global Superstore_Cleaned_Data.xlsx` – Cleaned dataset

## Learning Outcome

Through this project, I gained practical experience in data cleaning, data preparation, and handling data quality issues using Microsoft Excel.
